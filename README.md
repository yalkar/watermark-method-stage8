# Stage 8 — print-camera эксперимент

В этом архиве собраны материалы финального эксперимента с текущей версией блочного метода встраивания цифрового водяного знака.

В эксперименте использовалось 50 изображений. В каждое изображение встраивался 256-битный ЦВЗ, после чего изображения подготавливались к фотопечати. Затем каждое напечатанное изображение фотографировалось на телефон со штатива по три раза.

Перед извлечением ЦВЗ фотографии проходили геометрическую синхронизацию с цифровым эталоном, чтобы компенсировать перспективные и другие геометрические искажения, появившиеся при съемке.

Для всех 50 изображений использовалась одна и та же 256-битная последовательность ЦВЗ.

## Структура архива

### `full_experiment_images/`

Здесь лежат исходные изображения, использованные в эксперименте.

В папке `set_2/` находятся 50 изображений с номерами от `000001` до `000050`.

### `full_experiment_stage8_256_r15/20260817_161337/`

Здесь находятся материалы этапа встраивания ЦВЗ и подготовки изображений к печати.

- `PRINT_READY/` — квадратные изображения 512×512 после встраивания ЦВЗ. Эти изображения также используются как цифровые эталоны при геометрической синхронизации фотографий.
- `PRINT_READY_3x4/` — макеты, подготовленные для фотопечати. Квадратная область изображения при печати имела размер 6×6 см.
- `metadata/` — параметры встраивания для каждого изображения, необходимые при извлечении ЦВЗ.
- `watermark_256_bits.txt` — исходная 256-битная последовательность ЦВЗ. Она использовалась для всех изображений.
- `digital_control.csv` — результаты цифровой проверки после встраивания, до печати и съемки.
- `experiment_manifest.json` — параметры подготовительного запуска.

### `Итоговый список снимков/`

Здесь лежат оригинальные фотографии напечатанных изображений с телефона до какой-либо обработки.

Для каждого изображения было сделано по три фотографии. Большая часть снимков сохранена в HEIC, несколько снимков — в JPG. Финальный скрипт обработки поддерживает оба формата.

### `final_phone_stage8_auto_sync_final/20260831_223251/`

Здесь находятся результаты финального print-camera прогона.

В корне папки лежат:

- `auto_mapping.csv` — соответствие групп фотографий цифровым изображениям `000001`–`000050`;
- `sync_results.csv` — результаты извлечения ЦВЗ для каждого из 150 снимков, включая BER;
- `summary_by_matched_image.csv` — сводка результатов по каждому изображению;
- `overall_summary.csv` — общая статистика эксперимента.

В папке `cases/` для каждого изображения и каждого из трех снимков сохранены:

- `synchronized.png` — фотография после геометрической синхронизации;
- `extracted.txt` — извлеченная 256-битная последовательность ЦВЗ;
- `registration.json` — информация о выполненной геометрической регистрации.

Исходный ЦВЗ из `watermark_256_bits.txt` и файлы `extracted.txt` позволяют при необходимости заново пересчитать BER и посмотреть распределение битовых ошибок для каждого снимка.

## Код

Основные файлы реализации находятся в корне архива.

- `method_block.py` — основная реализация блочного метода встраивания и извлечения ЦВЗ.
- `registration.py` — геометрическая синхронизация фотографии с цифровым эталоном.
- `prepare_full_print_experiment_stage8.py` — подготовка исходных изображений, генерация ЦВЗ, встраивание и цифровая проверка.
- `prepare_polaroid_3x4_stage8.py` — подготовка макетов 3:4 для фотопечати.
- `run_full_phone_auto_sync_stage8_mixed.py` — финальная обработка фотографий: чтение HEIC/JPG, сопоставление с цифровыми эталонами, геометрическая синхронизация, извлечение ЦВЗ и расчет BER.
- `requirements.txt` — зависимости проекта.

## Параметры финального эксперимента

- размер рабочего изображения — 512×512;
- длина ЦВЗ — 256 бит;
- размер блока — 8×8;
- repetition — 15;
- профиль — `block8_256_r15`;
- количество изображений — 50;
- количество фотографий каждого изображения — 3;
- всего фотографий — 150;
- съемка выполнялась на телефон со штатива;
- извлечение ЦВЗ выполнялось после геометрической синхронизации.

## Как запустить

### 1. Установить зависимости

Сначала необходимо установить зависимости проекта:

```powershell
python -m pip install -r requirements.txt
```

Для чтения фотографий в формате HEIC также нужен пакет `pillow-heif`:

```powershell
python -m pip install pillow-heif
```

### 2. Подготовить изображения и встроить ЦВЗ

Исходные изображения должны находиться в папке:

```text
full_experiment_images/set_2/
```

Запуск:

```powershell
python prepare_full_print_experiment_stage8.py
```

Скрипт берет 50 исходных изображений, подготавливает их к размеру 512×512, генерирует общий 256-битный ЦВЗ, встраивает его в изображения и выполняет цифровую проверку.

Каждый новый запуск создает отдельную папку:

```text
full_experiment_stage8_256_r15/<дата_и_время_запуска>/
```

В финальном эксперименте использовалась папка:

```text
full_experiment_stage8_256_r15/20260817_161337/
```

### 3. Подготовить изображения для фотопечати

После встраивания необходимо подготовить макеты 3:4:

```powershell
python prepare_polaroid_3x4_stage8.py
```

Файлы, которые использовались в финальном эксперименте, находятся в:

```text
full_experiment_stage8_256_r15/20260817_161337/PRINT_READY_3x4/
```

Именно эти изображения отправлялись в фотопечать.

### 4. Подготовить фотографии после печати

После печати для каждого изображения необходимо сделать по три фотографии.

Исходные фотографии с телефона нужно положить в папку:

```text
Итоговый список снимков/
```

Финальный сценарий рассчитан на 150 фотографий: 50 изображений × 3 снимка.

Поддерживаются форматы `HEIC`, `HEIF`, `JPG`, `JPEG` и `PNG`.

### 5. Запустить синхронизацию и извлечение ЦВЗ

Финальный этап запускается командой:

```powershell
python run_full_phone_auto_sync_stage8_mixed.py
```

Скрипт считывает фотографии, разбивает их на группы по три снимка и автоматически определяет, какому из 50 цифровых эталонов соответствует каждая группа.

После сопоставления для каждого снимка выполняется геометрическая синхронизация, извлекается 256-битный ЦВЗ и рассчитывается BER.

Каждый новый запуск сохраняется в отдельную папку:

```text
final_phone_stage8_auto_sync_final/<дата_и_время_запуска>/
```

Результаты финального эксперимента из этого архива находятся в:

```text
final_phone_stage8_auto_sync_final/20260831_223251/
```

Скрипт `run_full_phone_auto_sync_stage8_mixed.py` использует цифровые эталоны, metadata и исходный ЦВЗ из:

```text
full_experiment_stage8_256_r15/20260817_161337/
```

Этот путь указан в переменной `EXPERIMENT_ROOT`.

Если заново запустить `prepare_full_print_experiment_stage8.py`, будет создана новая папка с новой датой и временем. Если новый набор нужно использовать для повторного полного эксперимента, необходимо также изменить `EXPERIMENT_ROOT` в `run_full_phone_auto_sync_stage8_mixed.py`.

### 6. Просмотр уже полученных результатов

Для просмотра результатов повторно запускать эксперимент не нужно.

Финальные результаты находятся в:

```text
final_phone_stage8_auto_sync_final/20260831_223251/
```

Основные файлы с результатами:

- `sync_results.csv` — результаты для каждого из 150 снимков;
- `summary_by_matched_image.csv` — сводка по каждому изображению;
- `overall_summary.csv` — общая статистика эксперимента;
- `auto_mapping.csv` — соответствие групп фотографий цифровым эталонам.

В папке `cases/` находятся синхронизированные изображения, извлеченные ЦВЗ и данные геометрической регистрации для каждого снимка.
